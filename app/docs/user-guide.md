# คู่มือใช้งาน AP+forms

## เข้าสู่พื้นที่ทำงาน

เปิดเว็บ AP+forms ใช้ชื่อบัญชีและรหัสผ่านที่ตั้งหลังรับคำเชิญ ผู้ดูแลและผู้สร้างฟอร์มเลือก **สร้างและจัดการฟอร์ม** เพื่อเปิด Builder ชื่อบัญชีจะแสดงระหว่างทำงานร่วมกัน หากเพิ่งติดตั้ง ให้ตั้งองค์กรและผู้ดูแลคนแรกตามคู่มือองค์กรก่อน

## สร้างและจัดฟอร์ม

1. สร้างฟอร์มจากหน้ารายการ แล้วตั้งชื่อและคำอธิบาย
2. จัดหน้าหรือ Section ตามลำดับที่ต้องการให้ผู้ตอบเห็น
3. เพิ่มคำถามและบล็อกประกอบ เช่น หัวข้อ ข้อความ รูปภาพ หรือสื่อ
4. กำหนดคำถามที่ต้องตอบ และตรวจการแสดงผลด้วย **Preview**
5. ตรวจสถานะการบันทึกก่อนออกจากฟอร์มหรือเผยแพร่

คำอธิบายรองรับการขึ้นบรรทัดใหม่ เหมาะกับคำชี้แจงที่มีหลายข้อหรือมีตัวอย่างประกอบ

## กำหนดเงื่อนไข

**Conditional Display** ใช้แสดงหรือซ่อนบล็อกตามคำตอบ ส่วน **Page Routing** ใช้กำหนดหน้าถัดไปเมื่อผู้ตอบตรงตามเงื่อนไข สามารถตรวจภาพรวมได้ในมุมมอง Logic

หากต้องการคำถามเพิ่มเติมเฉพาะบางตัวเลือก ให้เลือกคำถามแบบเลือกหนึ่งข้อหรือหลายข้อ แล้วเพิ่ม **Child Blocks** ใต้ตัวเลือกนั้น บล็อกจะแสดงเมื่อผู้ตอบเลือกตัวเลือกที่เกี่ยวข้อง และซ่อนเมื่อเลิกเลือก

## ตรวจรูปแบบคำตอบ

คำถามแบบข้อความสั้นและข้อความยาวรองรับ **Response Validation** เช่น ไม่รับค่าบางค่า หรือไม่รับข้อความที่มีอักขระที่กำหนด

ตัวอย่าง: ป้องกันการใช้เครื่องหมาย `-` แทนคำตอบ

1. เลือกคำถามข้อความ แล้วเปิด **Response Validation**
2. เลือกกฎ **ห้ามมีข้อความ / อักขระนี้**
3. ใส่ `-` ในช่องค่าที่ห้าม
4. ตั้งข้อความแจ้งเตือน เช่น “กรุณากรอกคำตอบเป็นข้อความ”

หากต้องการห้ามเฉพาะคำตอบที่เป็น `-` ทั้งคำตอบ ให้ใช้กฎห้ามค่าที่ตรงกัน แทนกฎห้ามมีอักขระนี้

## เผยแพร่ฟอร์ม

เลือก **Publish** เพื่อสร้างฉบับเผยแพร่และลิงก์สำหรับผู้ตอบ หลังจากนั้นการแก้ไขจะอยู่ในฉบับร่าง จนกว่าจะเลือก **Publish Changes**

- การเผยแพร่การแก้ไขใช้ลิงก์เดิม
- ตั้งเวลาเปิด–ปิดรับคำตอบได้จาก **Publish Settings** โดยใช้เวลาท้องถิ่นที่แสดงในหน้าจอ
- **Close Form** ปิดรับคำตอบ และ **Reopen** เปิดรับด้วยลิงก์เดิม
- **Regenerate Public Link** สร้างลิงก์ใหม่และยกเลิกลิงก์เก่า ควรแจ้งผู้ที่ได้รับลิงก์เดิมด้วย
- **Archive** เก็บฟอร์มออกจากการใช้งาน ลิงก์จะหยุดรับคำตอบ แต่คำตอบที่มีอยู่ยังเก็บไว้

ตรวจฟอร์มผ่านลิงก์สำหรับผู้ตอบอีกครั้งก่อนแชร์ โดยเฉพาะเงื่อนไข คำถามที่ต้องตอบ และกำหนดเวลา

## ดูคำตอบ

เปิด **Responses** เพื่อดูรายการและสรุปคำตอบ คำตอบจะอ้างอิงเวอร์ชันที่ผู้ตอบใช้งาน จึงยังอ่านคำตอบเก่าได้เมื่อฟอร์มมีการแก้ไขภายหลัง

เลือกสรุปทั้งหมดหรือเฉพาะรายการที่เลือกได้ หากมีคำตอบจากแอปที่เชื่อมต่อ สามารถกรองตามแหล่งที่มาและดูข้อมูลประกอบของแอปได้

## จัดคลังคำถาม

เปิด **Question Banks** เพื่อสร้างคลัง เพิ่มคำถาม และจัดแท็ก คำถามรองรับการเลือกหนึ่งข้อ หลายข้อ จริง–เท็จ ข้อความสั้น เรียงลำดับ จับคู่ และลากวาง

กำหนดโจทย์ ตัวเลือกหรือกิจกรรม และคำตอบที่ถูกต้องให้ครบ คำถามที่ผ่านการตรวจจะมีสถานะพร้อมใช้ สามารถทดลองกิจกรรมก่อนนำไปจัดชุดได้

การนำเข้าและส่งออกใช้ไฟล์แพ็กเกจ JSON มีไฟล์ตัวอย่างใน [question-bank-templates](../public/question-bank-templates/) รูปประกอบคำถามจัดการตาม [คู่มือสื่อ](../public/assets/question-media/README.md)

## จัดชุดคำถาม

เปิด **ชุดคำถาม** แล้วสร้างชุดใหม่ เลือกคำถามจากคลังโดยตรง หรือเพิ่มกลุ่มสุ่มโดยกำหนดคลัง ประเภท ระดับความยาก และแท็ก

ใช้ **ตรวจการจัดชุด** เพื่อตรวจว่ามีคำถามเพียงพอและพร้อมใช้งาน ก่อนเลือก **เผยแพร่ Version ใหม่** แต่ละเวอร์ชันเก็บชุดคำถามที่เลือกไว้ การแก้คลังภายหลังจึงไม่เปลี่ยนคำถามในเวอร์ชันที่เผยแพร่แล้ว

การทดลองชุดคำถามใช้สำหรับตรวจประสบการณ์ตอบ สามารถกดถัดไปและทดลองตรวจคำตอบได้ โดยไม่บันทึกเป็นผลสอบ
