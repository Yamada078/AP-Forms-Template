# ทดลองเชื่อมฟอร์มกับแอปของคุณ

ตัวอย่างนี้ให้เซิร์ฟเวอร์ตัวอย่างอ่านฟอร์มและส่งคำตอบเข้า AP+forms รหัสเชื่อมต่ออยู่ฝั่งเซิร์ฟเวอร์ ผู้ทดลองไม่ต้องเขียนตัวเรียก API เอง

## เตรียมฟอร์มและสิทธิ์

1. ติดตั้ง AP+forms และตั้งองค์กรตาม [คู่มือองค์กร](organization-guide.md)
2. สร้างฟอร์มทดลองที่ไม่มีข้อมูลจริง เพิ่มคำถาม และ Publish
3. ใน **กำหนดสิทธิ์ผู้ตอบ** เลือก **ทุกคนที่มีลิงก์** สำหรับตัวอย่าง API นี้
4. ผู้ดูแลเปิด Applications สร้าง Application ชื่อ “Integration demo”
5. ให้สิทธิ์ `read_form_schema` และ `submit_response` แล้วเลือกฟอร์มใน Allowed Forms
6. สร้าง Integration Key และคัดลอก Public ID จาก Publish Settings

## เปิดแอปตัวอย่าง

เปิด PowerShell 7 ที่ root ของโปรเจกต์:

```powershell
$env:API_BASE_URL = "https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev"
$env:PUBLIC_FORM_ID = "YOUR_PUBLIC_FORM_ID"
$env:INTEGRATION_KEY = Read-Host "Integration key" -MaskInput
node examples/app-integration-server.mjs
```

เปิด `http://127.0.0.1:8812` กดอ่านฟอร์ม หน้าเว็บจะแสดง schema และ Published Version กรอกชื่อและ JSON คำตอบโดยใช้ ID คำถามจาก schema แล้วส่งคำตอบ ตัวอย่างนี้ใช้ JSON เพื่อทดลองสัญญา API จึงยังไม่ได้สร้างหน้าตอบจากคำถามทุกชนิดให้อัตโนมัติ

หลังส่งสำเร็จ เปิด Responses ใน AP+forms คำตอบจะแสดงว่าเข้ามาจาก Application ตัวอย่าง ระบบกำหนดแอปต้นทางจากรหัสที่ยืนยันแล้ว

หยุดเซิร์ฟเวอร์ด้วย Ctrl+C แล้วลบรหัสออกจาก environment:

```powershell
Remove-Item Env:INTEGRATION_KEY
```

ตัวอย่างผูกกับ `127.0.0.1` สำหรับทดลองบนเครื่องเท่านั้น ไม่มีบัญชีสมาชิกของเว็บตัวอย่าง ก่อนนำแนวทางนี้ไปใช้ในแอปจริง ให้เซิร์ฟเวอร์แอปตรวจบัญชีผู้ใช้และสิทธิ์ของตนก่อนเรียก API

## ถ้าแอปของคุณมีระบบลงทะเบียนสมาชิก

ขั้นตอนฝั่งแอปคือ: สมาชิกเข้าสู่แอป → เซิร์ฟเวอร์แอปตรวจ session และสิทธิ์ → อ่าน schema → แอปแสดงหน้าตอบ → เซิร์ฟเวอร์ส่งคำตอบ → AP+forms เก็บคำตอบและแอปต้นทาง

การส่ง ID สมาชิกใน `respondentMeta` เป็นข้อมูลที่แอปแจ้ง รุ่นนี้ยังไม่ยืนยันว่าเป็นบัญชีสมาชิก AP+forms และไม่อนุญาตใช้แทนการเข้าสู่ระบบของฟอร์มที่จำกัดสมาชิก ดู [ขอบเขตการเชื่อมบัญชี](organization-guide.md#เชื่อมเว็บที่มีสมาชิกอยู่แล้ว)

แอปภายนอกจะอยู่บนโฮสต์ใดก็ได้ หากเรียก HTTP API ได้ ตัว AP+forms รุ่นนี้ยังติดตั้งบน Cloudflare Workers/D1 ตามคู่มือ การรองรับโฮสต์อื่นต้องปรับส่วนฐานข้อมูลและการทำงานร่วมกันเพิ่มเติม
