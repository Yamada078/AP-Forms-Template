# ภาษาของหน้าจอ

AP+forms เลือกภาษาไทยหรืออังกฤษได้ทั้งหน้าบัญชีองค์กร สิทธิ์ผู้ตอบ Builder, Logic, Responses คลังคำถาม ชุดคำถาม และหน้าผู้ตอบ

## เลือกภาษา

ใช้เมนู **Language / ภาษา** ที่ด้านล่างของหน้าจอ ครั้งแรกระบบใช้ภาษาของเบราว์เซอร์ หากเป็นภาษาไทยจะแสดงไทย ภาษาอื่นเริ่มเป็นอังกฤษ ระบบจำภาษาที่เลือกในเบราว์เซอร์และใช้ร่วมกันทุกหน้าของระบบเดียวกัน

เปิดลิงก์พร้อม `?lang=en` หรือ `?lang=th` ได้ เช่น `/account?lang=en` ค่าจากลิงก์มีลำดับก่อนค่าที่จำไว้ หากใช้โหมดส่วนตัวหรือปิดการเก็บข้อมูลในเบราว์เซอร์ อาจต้องเลือกใหม่ในครั้งถัดไป

การสลับภาษาวาดหน้าจอใหม่โดยไม่โหลดหน้าเว็บซ้ำ และเก็บข้อความในช่องที่กำลังกรอกไว้ ปิดกล่องตั้งค่าหรือหน้าต่างย่อยก่อนสลับภาษา

## ข้อความที่เปลี่ยน

ปุ่ม เมนู คำอธิบาย ข้อความระบบ และรูปแบบวันเวลาใช้ภาษาที่เลือก ฟอร์มที่สร้างใหม่ใช้ข้อความเริ่มต้นตามภาษานั้นด้วย

ชื่อองค์กร ชื่อบัญชี ชื่อฟอร์ม คำถาม ตัวเลือก ข้อความตรวจคำตอบที่เขียนเอง และคำตอบที่เก็บไว้ยังคงข้อความต้นฉบับ การสลับภาษาไม่เขียนข้อมูลใน D1 ใหม่ หากต้องการฟอร์มภาษาอังกฤษ ให้เขียนเนื้อหาใน Builder เป็นอังกฤษ

แม่แบบในคลังคำถามมีทั้งไทยและอังกฤษ เมื่อคัดลอกแม่แบบมาใช้ เนื้อหาจะเป็นของคลังคุณและคงภาษานั้นไว้

## เพิ่มหรือแก้คำแปล

คำแปลอยู่ใน `public/i18n-translations.js` และระบบเลือกภาษาอยู่ใน `public/i18n.js` คีย์ของคำแปลใช้ข้อความหน้าจอภาษาไทยเดิม

ใช้ `__apText` กับข้อความระบบ และ `__apHtml` กับแม่แบบ HTML ส่วนข้อความที่แทรกในแม่แบบจะคงเดิมและยังต้องผ่านตัวช่วย escape ตามเดิม ใช้ `APFormsI18n.message` กับข้อความจากเซิร์ฟเวอร์ และ `APFormsI18n.labels` กับตารางชื่อสิทธิ์หรือชนิดที่เก็บไว้แล้ว

แต่ละหน้าลงทะเบียนตัววาดหน้าจอด้วย `APFormsI18n.register` ให้คงข้อมูลที่กำลังทำงานไว้ และไม่ส่งคำตอบหรือสร้างรายการใหม่เพียงเพราะมีการเปลี่ยนภาษา

เมื่อแก้คำแปล ให้ตรวจทั้งสองภาษา รวมถึงหน้าจอมือถือ ช่องที่ยังกรอกไม่เสร็จ และหน้าส่งคำตอบสำเร็จ รัน `npm test` กับ `npm run check:build` จากโฟลเดอร์ `app` และปรับคู่มือทั้งสองภาษาหากพฤติกรรมเปลี่ยน
